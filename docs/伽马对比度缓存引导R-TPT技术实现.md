# 伽马＋对比度视图的 Tip-F 缓存引导 R-TPT

本方案以 CLIP RN50、NEU-CLS 六类、每类 16 张训练样本构建的 Tip-Adapter-F（下称 Tip-F）缓存为基础。R-TPT 在**每张待测图像**上临时调整文本提示，并用 Tip-F 缓存分数引导低熵视图选择及最终融合。训练数据划分为 900 张训练、360 张验证、540 张测试；实际用于训练 F 适配器的是每类 16 张，共 96 张。

按目前关注的场景，仅统计强变暗、强变亮、局部反光、强变亮加反光四种合成条件。“强变暗＋反光”的历史原始结果仍保留，但不纳入此处的方案比较。四条件验证集每种增强种子共有 1440 次判断：伽马＋对比度视图为 1085/1440（种子 0）、1083/1440（种子 1），单独对比度为 1070/1440、1073/1440。独立测试集种子 0 中，伽马＋对比度为 **1641/2160（75.97%）**，单独对比度为 1629/2160（75.42%），静态 Tip-F 为 1550/2160（71.76%）。因此它是当前已测候选中、针对这些**合成条件**的首选；2160 次判断来自同一批 540 张图像在四种条件下的重复评估。四条件范围是在查看原五条件测试结果后确定的，所以这些合计数属于事后重算，不是一轮新的独立选模；原方案在五条件验证时已经选为第一名。

## 1. 文本端

六类缺陷分别为 `crazing`、`inclusion`、`pitted surface`、`patches`、`rolled-in scale`、`scratches`。每类使用与 Tip-Adapter 相同的完整文本：

```text
a photo of {class_name}, a type of steel surface defect.
```

Tip-F 的静态文本分支用冻结的 RN50 CLIP 文本编码器分别编码六句话，再对每个类别特征做 L2 归一化，形成文本权重矩阵 `W ∈ R^(1024×6)`。R-TPT 的动态文本分支把开头 `a photo of` 对应的 **3 个上下文 token 向量**设为可学习参数，类名和后缀 `, a type of steel surface defect.` 保持固定，六类共享这组上下文。初始状态下，两条文本分支的特征最小余弦相似度经实测为 1.000000；这避免了把两种提示模板的差异误当成算法收益。

测试时只更新这 3 个上下文向量。类别名、固定后缀、CLIP 文本编码器、图像编码器和 Tip-F 适配器均不随待测样本更新。下一张图像处理前，上下文回到 `a photo of` 的初始化向量。

实现见 [`experiment.py`](../src/experiment.py) 的 `set_tip_prompt`、`tune`，以及 [R-TPT 子模块](../third_party/R-TPT/clip/custom_clip.py)中的 `PromptLearner`。

## 2. 图像端

对一张待测 RGB 图像生成 **24 个视图**：

1. 视图 0：双三次插值缩放到短边 224，再中心裁剪为 224×224；它是确定性的原图视图。
2. 视图 1–23：各自从同一输入图像出发，做相同的缩放和中心裁剪，再依次做伽马调整和对比度调整。两项调整的系数各自独立从 `[0.85, 1.15]` 均匀采样。
3. 每个视图转为 `[0,1]` 张量。R-TPT 模型内部按 CLIP 的均值、标准差归一化，再送入冻结的 RN50 图像编码器；输出图像向量做 L2 归一化。

这个被选中的视图方案不使用随机裁剪、翻转或原版 AugMix。伽马和对比度调整只为同一待测图像生成轻度变化的视图，**不改变原始图像文件，也不构成离线训练数据增强**。实现见 [`augmentations.py`](../src/augmentations.py) 的 `LightingJitter`、`ViewAugmenter` 和 `gamma_contrast` 候选。

强变暗、强变亮与局部反光是在**评估时**先作用于待测输入、再生成上述 24 个视图的合成压力条件；实际推理不必判断图像属于哪一类，也不向真实图像人为加亮斑。压力条件中的亮度系数分别为 `0.55`、`1.55`；局部反光用白色椭圆亮斑混合，中心可饱和至 255，位置由原图哈希确定以保证复现。相关实现见 [`lighting_conditions.py`](../src/lighting_conditions.py) 与 [`search_lighting.py`](../scripts/search_lighting.py)。这不是相机曝光或真实金属镜面反射的物理模拟。

## 3. 训练时怎么做

**离线阶段训练 Tip-F 适配器，不训练 R-TPT 提示。**沿用 Tip-Adapter 工作区已有的 16-shot 图像特征缓存：`K₀ ∈ R^(1024×96)` 是缓存键，`V ∈ R^(96×6)` 是对应的 one-hot 类别值。当前实验没有重新划分数据或重建缓存。从 `K₀ᵀ` 初始化一个无偏置线性层 `A ∈ R^(96×1024)`，冻结 CLIP 图像和文本编码器，只训练 `A`。

训练种子为 1，选取六类各 16 张，共 96 张；批量大小 96，训练 20 轮。训练图像做随机尺度裁剪到 224（面积范围 0.5–1.0）、概率 0.5 的水平翻转及 CLIP 归一化。优化器为 AdamW，初始学习率 `0.001`、`eps=1e-4`，余弦退火调度。设归一化图像特征为 `u`，训练时的类别分数是

```text
训练分数 = 100 · uW + 3 · exp[-(1 - uAᵀ)]V
训练损失 = CrossEntropy(训练分数, 类别标签)
```

每轮只在验证集上计算准确率，准确率相同时用较低交叉熵损失打破平局。选中的第 20 轮在训练阶段固定系数（`β=1, α=3`）下，验证准确率为 95.83%。保存该轮适配器权重到 `outputs/tip_f_val_selected_16shot_seed1.pt`。这个实现使用 float32 适配器，与原 Tip-Adapter `main.py` 的半精度训练不完全相同；也没有使用其按测试准确率选训练轮次的做法。

随后固定适配器，在**完整验证集**的预计算图像特征上网格搜索融合系数：`β` 的 200 个点覆盖 `0.1–12`，`α` 的 20 个点覆盖 `0.1–5`。得到 `β=0.6381909548`、`α=5.0`，静态 Tip-F 验证准确率为 346/360（96.11%）。搜索没有用测试集；`α=5.0` 是当前网格的上界。实现见 [`train_tip_f.py`](../scripts/train_tip_f.py) 与 [`experiment.py`](../src/experiment.py) 的 `select_hyperparameters`。

## 4. 实际使用时怎么做

系统启动时加载冻结的 RN50、六类文本提示、Tip-F 适配器权重、缓存值 `V`，并固定 `β`、`α`。对每张新图像独立执行：

1. 生成确定性原图视图和 23 个随机伽马＋对比度视图。
2. 用冻结的图像编码器一次性提取 24 个归一化图像向量 `u_i`。
3. 为所有视图计算 Tip-F 缓存分数，并由视图间图像特征相似度计算最终融合权重。
4. 把 R-TPT 提示及其优化器状态重置到初始状态；用缓存增强后的类别分数挑出低熵视图，对 3 个上下文向量执行 **1 次**测试时梯度更新。
5. 用更新后的文本提示为所有 24 个视图重新算类别分数，逐视图加上固定的缓存分数，再按相似度权重汇总；取最高分作为六类缺陷之一。
6. 丢弃该图像的临时提示更新；下一张图像重新从初始提示开始。待测图像及预测不会写入缓存，也不会继续训练 Tip-F。

因此部署时只需要当前图像及离线保存的权重和缓存，无需待测样本标签或跨图像积累状态。完整的现有实验入口是 [`search_lighting.py`](../scripts/search_lighting.py)；它遍历带标签的数据集、计算准确率，**并不是单张无标签图片的封装接口**。将其接入生产系统时，应按上述同一计算路径封装单图推理函数。

## 5. R-TPT 如何使用

R-TPT 在此方案中负责**每张图像的临时提示适应**，而非更新 CLIP 编码器。初始提示及图像特征先给出 24 个视图的融合分数：

```text
z_i(C₀) = CLIP_图文分数(u_i, C₀) + α · c_i
H_i = -Σ_k softmax(z_i)_k · log softmax(z_i)_k
```

其中 `C₀` 是 `a photo of` 的三个初始上下文向量，`c_i` 是第 `i` 个视图的 Tip-F 缓存类别分数。按熵从低到高选前 `max(1, floor(24×0.1))=2` 个视图，用两者熵的均值作为目标，AdamW 学习率 `0.005` 更新一次 `C`。这是**缓存引导**：视图选择与提示梯度都使用“提示分数＋缓存分数”，缓存分数本身不参与梯度更新。

R-TPT 的图像相似度加权用于最终融合，而不是仅保留这 2 个低熵视图。对每个视图 `i`，以 `u_i · u_j` 计算它与其他视图的余弦相似度；去掉自身，取最相近的 20 个值求平均为 `s_i`，再计算 `q_i = softmax(s_i / 0.01)`。最终对**全部 24 个视图**求和：

```text
最终类别分数 = Σ_(i=0)^23 q_i · [CLIP_图文分数(u_i, C更新后) + α · c_i]
```

第一视图只是确定性的原图视图，并未被强制单独决策。原版 R-TPT 的 AugMix 视图已替换为更适合本轮钢材缺陷实验的轻伽马＋对比度视图；当前实现没有做对抗图像更新。测试时重置、熵最小化和加权融合分别见 [`experiment.py`](../src/experiment.py) 的 `tune` 与 [`search_augmentations.py`](../scripts/search_augmentations.py) 的 `evaluate`。

## 6. Tip-Adapter 缓存如何使用

训练结束后，把适配器的权重转置为新的缓存键 `K_F = Aᵀ ∈ R^(1024×96)`；96 个 one-hot 缓存值 `V` 保持不变。对任一归一化视图特征 `u_i`：

```text
亲和度    a_i = u_i K_F                         # 96 个训练样本的匹配分数
缓存分数  c_i = exp[-β · (1 - a_i)] V           # 6 类分数
```

F 训练后没有对 `K_F` 再做 L2 归一化，因此 `a_i` 是学习后的点积亲和度，不必然是严格的余弦相似度。`β=0.6381909548` 控制亲和度经指数函数映射后的形状，`α=5.0` 控制缓存分数加入图文分数时的权重。缓存有两次作用：首先引导 R-TPT 的低熵视图选择与提示更新，其次参与更新后所有视图的最终类别融合。缓存键和值对同一张待测图像的 24 个视图重复使用，**不会因测试时提示更新而重新训练或写入新样本**。

用作对照的静态 Tip-F 只看第 0 个原图视图，计算 `100 · u₀W + α · c₀`；它不生成测试时提示梯度，也不对 24 个视图做相似度融合。这样可以直接检验整套“缓存引导 R-TPT＋多视图融合”的效果，但不能把差异单独归因于提示更新或视图增强其中之一。
